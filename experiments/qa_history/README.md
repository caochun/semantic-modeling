# 历史 QA 实验

`build_targeted_batch_007.py` 依赖本地旧发布构建器和评测资料，保存当时的负例实验。

`batch05_helpers/` 按原字节保留第五批的临时组装、修订、覆盖、模型响应解析、来源绑定和备份脚本。它们包含当时的固定路径、版本及手工决定，属于过程记录，不是可泛用的新批次审核器。尤其解析工具曾处理不合法的模型 JSON，绑定工具承接当时的来源核对决定；这些历史处理不能被当作模型原始 pass，也不能用于自动批准新 QA。

当前命令从 `qa_pipeline/` 执行，默认不加载这里的临时工具。审核原始响应继续在本地原目录及备份包中保留；版本化数据的 `snapshot.json` 登记原文件摘要，不通过运行历史工具重写冻结记录。
