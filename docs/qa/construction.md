# 直流站运行问题 QA：文档筛选与构建记录

目标是帮助定位直流站运行问题、解释现象并给出处置路径。当前资料主体是姑苏换流站，第一版以姑苏站文档为范围，不能把它泛化为所有直流站的现行规程。

复用已有全量审计，并重新核对全部业务文件的 SHA-256。`rawdoc` 共190个文件，其中182个业务文件、174份不同内容；7组完全相同文件含8个冗余副本。下表按174份不同内容统计：

## 采用的方法

研究调研参考了 [GraphGen](https://arxiv.org/abs/2505.20416)、[pdfQA](https://arxiv.org/abs/2601.02285) 和 [Roundtrip Consistency](https://arxiv.org/abs/1906.05416)。实际实现以章节/表格规则提取、显式整理的关联上下文和少量证据组织问答为主；不能将“参考论文”理解为已经实施完整的研究流水线，也没有沿用论文的准确率。

| 研究中的方法 | 当前实际实现 | 尚未实现的核心部分 |
|---|---|---|
| GraphGen的知识结构、掌握评估和多层QA采样 | 建立完整业务单元索引，整理部分有来源依据的依赖 | 未实施实体/关系图驱动的生成、目标模型知识掌握打分与薄弱知识采样；未系统为每条链路构建多种任务 |
| pdfQA的内部与扩展有效性验证 | 保存直接证据及关联章节；人工核对部分跨册限制和歧义 | 保存扩展上下文本身不是扩展有效性验证；没有逐条完成关联来源复核和语义过滤 |
| Roundtrip Consistency的独立复答过滤 | GLM答案盲复答28次，当前版本覆盖23条候选，由Codex对照来源 | 未对全部候选执行复答、按事实/分支/顺序核验及过滤 |

代码中事故预案主要使用固定问题模板，答案为完整预案原文；运行规定、操作票、保护表和历史案例也主要由规则转换。50条自然QA来自`focused_qa.json`，包含条件、恢复、错误前提及跨册整合，但不是覆盖全部业务单元的批量多问法生成流程。

1. **以完整业务单元切分。** 故障预案跨页保留；操作票从操作任务一直保留到最后检查与注项。不能用固定字符数切断分支或操作链。
2. **保存直接证据与关联上下文。** 事故通则、倒闸管理、预案引用和部分跨册运行限制一起保存。关联是显式整理的范围，不声称穷尽全文依赖。
3. **先构建完整原文型QA，再构建条件型自然问答。** 原文型QA保留条款、顺序与禁止项；自然问题覆盖诊断、不同运行方式、恢复、错误前提、来源冲突和条件不足。
4. **所有操作事实必须有文档依据。** 不虚构新案例、处置成功结果或未提供的定值；历史软件修改不能生成成运行人员自行解除联锁的授权。
5. **分别做结构验证与独立复答。** 前者核对证据偏移和声明的检查项，后者让GLM只看完整证据和问题，并由Codex对照原文分析差异。

旧Word第三分册原先提取为空，本次通过Word原生FIB/CLX/PCD恢复282,560个主正文字符位置。按原始单元格结束标记分离表后标题，按目录顺序解析82个章节标题，避免重复“运行规定”误配。自动编号、图像、表格几何没有恢复，相关单元保留为待核实。保护跳闸XLS保留工作表、行列和显式合并单元格；普通空白不向下填充，不把空白当作现场“不动作”的证明。

## 实际结果

**1,997条候选**，其中1,947条按完整原文构建，50条由Codex结合证据组织问题和回答。下表按构建组互斥统计：

| 构建组 | 条数 |
|---|---:|
| 完整故障预案 | 172 |
| 事故处理通则 | 3 |
| 完整运行约束 | 49 |
| 完整操作任务 | 1,542 |
| 保护出口对应关系 | 155 |
| 历史案例记录 | 22 |
| 厂家异常文字规定 | 4 |
| 条件诊断、流程整合及其他自然问答 | 50 |

另导出**455条诊断/处置子集**，从总集排除批量操作票，避免后续训练被设备编号重复任务主导。这个子集与总集重叠，不能当作额外455条独立样本。

2,500个索引单元中，1,947个构成原文型QA、551个暂缓、2个仅保留目的/职责范围。551个暂缓单元包括427个含空白值的票任务、95个含设备/端子占位符的任务、27个未解析图表/过长/章标题单元，以及2个存在歧义的预案。暂缓单元的范围与原因均可查，不把它们计为已完成解决方案。

## 必须保留的来源问题

| 问题 | 本版处理 |
|---|---|
| 第五分册8.4“8个以下”与单列“7个”PF动作条件重叠 | 暂缓普通完整处置QA，仅生成说明条件重叠的QA，不重划互斥区间 |
| 第五分册9.22直流滤波器电流分支没有“等于” | 明示边界未定义；同时加入第三分册8.8运行方式和340A限制，但不自行认定两种电流判据相同 |
| 第三分册8.8全压禁止在线手动切除、LCC半压须满足额外条件 | 不能把2025年预案的电流条件改写成通用切除许可；核对现行适用条款 |
| 第五分册15.13.2.2.4“可判断未误报警”疑有笔误 | 暂缓该完整预案，仅保留歧义说明QA；无勘误时不擅自改字并给确定结论 |
| 第五分册10.3.2.7自注重复 | 保留原文并标记，不能据重复文字新增一步 |
| 案例p503未写具体根因、整改与验证结果 | 生成证据不足回答，不替厂家补结论 |
| 案例p500日期“22023” | 不把自动纠正后的日期当作已核实事实 |
| 不同装置的重启要求不同 | PCS-9540死机与PCS-9588B闭锁报警分别适用，不用通用重启模板 |
| 空白功率、占位设备、扫描定值与未核验图表 | 不填数字、不补接线、不把模板变成条件已确定的操作方案 |

## 检查结论与限制

构建检查通过：182个业务文件摘要重查、228,781次证据片段回查、声明检查项无遗漏、问题无完全重复。所有导出保留完整文本，未做输入或答案截断。最大答案10,523字符，最大上下文46,340字符；字符数不是token数。

GLM-5.3共完成28次答案盲复答，全部正常结束。首轮20题与修订8题合计对应**当前版本23条候选**；5条首轮记录因内容修订或隔离而失效。Codex对照来源记录了复答遗漏跨册限制、替代路径泛化及顺序呈现问题，没有直接用这些模型回答覆盖候选。该抽样是目的性选择，不估计全量正确率，也不是业务专家审核。详细记录见 [roundtrip_review.md](../../.semantic/qa_operations_20261008/roundtrip_review.md)。

当前数据状态仍是**候选**。已回查来源不代表来源本身正确、完整或有效。本版不能保证任何新型问题都有确定操作方案；资料范围外的问题应明确已知检查边界、请求补充关键条件并进入适用的报告/核查流程。

## 训练前的使用方式

优先审阅50条自然问答与455条诊断/处置子集，再按设备、故障类型和来源链路平衡采样操作票。`sft_direct.jsonl`提供问题→答案，供闭卷知识注入实验；`sft_context.jsonl`提供证据＋问题→答案，供基于文档作答实验。两者用途不同，不能因一个任务的表现就断言另一任务失败。

本版全部标为`train_candidate`，尚未在此次构建中送入训练。不能随机逐行切分出“独立测试集”：同一预案、相关运行限制、完整操作票和它们的自然改写可能泄漏。以前39题已参与开发设计，仍只用于开发回归。下一次训练应单独准备问题改写/条件泛化与来源隔离两类评测，分清“记住已学知识”与“理解未见资料”。

后续2026-10-08闭卷SFT先导实验从455条诊断/处置候选中使用415条，其中379条原文提取型、36条自然QA，详细配置与结果见[远程运行记录](../training/pilot-1.7b.md)。这次没有先完成训练方案所建议的成组多问法数据扩展，也没有建立已学知识的新问法泛化评测。候选证据可追溯和结构检查通过，不代表训练语料设计或微调收益已经得到验证；原文提取型占比较高也不能单独证明它是重复退化的原因，需要数据生成方法的对照实验。
